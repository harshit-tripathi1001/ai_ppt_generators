## Schema Field Reference

| Field | Type | Required | Description |
|---|---|---|---|
| `title` | string | Yes | Presentation title (displayed on title slide) |
| `subtitle` | string | No | Presentation subtitle |
| `theme` | string | Yes | Theme name (must match one of 7 registered themes) |
| `font_family` | string | Yes | Font name for all text elements |
| `font_size` | integer | Yes | Base font size in points (16–36) |
| `aspect_ratio` | string | Yes | `"16:9"` or `"4:3"` |
| `include_speaker_notes` | boolean | Yes | Whether to add speaker notes frames |
| `slides` | array | Yes | Array of `SlideContent` objects (min 1) |
| `slides[].layout` | string | Yes | One of 13 canonical layout names |
| `slides[].title` | string | Yes | Slide title |
| `slides[].bullets` | array of strings | No | Bullet point list |
| `slides[].body_text` | string | No | Free-form paragraph text |
| `slides[].speaker_notes` | string | No | Speaker notes text |
| `slides[].columns` | ColumnData | No | Two-column layout data |
| `slides[].kpi_metrics` | array of KpiMetric | No | Stats/KPI layout data |
| `slides[].table` | TableData | No | Table layout data |
| `slides[].chart` | ChartData | No | Chart layout data |
| `slides[].process_steps` | array of ProcessStep | No | Process flow layout data |
